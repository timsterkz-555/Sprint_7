# Sprint_7

API-тесты сервиса «Яндекс Самокат»: Java 11, Maven, JUnit 5, RestAssured и Allure.

Запуск на JDK 11:

```shell
mvn clean test
```

Проверяются создание и авторизация курьера, создание заказа с четырьмя
вариантами цвета и получение списка заказов — всего 14 запусков.
Тесты создают уникальные данные и удаляют курьеров или отменяют заказы после выполнения.

Результаты Allure: `target/allure-results`.
Тест входа без `password` ожидает HTTP 400; на текущем стенде запрос может
зависать и завершаться таймаутом. Ожидаемый результат не меняется под ошибку стенда.
